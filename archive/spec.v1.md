# Demo 規格 v1

## 概述
一句話概念: 在一個窄到讓人難受的盤面上疊史萊姆, 靠「把同色排在一起」換來盤面向左右延展, 玩家自己把牢房拓成球場。

Demo 要驗證的問題: 在窄盤面與隨機多色方塊下, 玩家能不能有意識地排出同色相鄰段, 而不是只能等運氣?

本規格只描述玩法規則與體驗流程。除非另有說明, 所有數字皆為初始值, 以數值同事的定案方向為底, 實際驗算不在本規格範圍。

## 核心循環
1. 玩家接到一個混色方塊(每格顏色各自獨立), 同時看得到下一塊的顏色組成與左右兩側當前目標色。
2. 玩家一邊避免堆到頂, 一邊刻意把左側目標色或右側目標色排成水平相鄰。
3. 整行填滿時消行: 該行清空得分, 行內目標色的水平相鄰段另外換成該側的解鎖點數。
4. 某側解鎖點數累積達到當階需求 → 該側向外延展一欄, 新欄以惰性格補到當前最低堆高。
5. 盤面變寬 → 水平空間變多, 排長段與求生都更容易 → 下一次解鎖更快到手。
6. 落速持續上升, 玩家在「現在消行求生」與「再忍一塊把段養長」之間反覆取捨, 直到堆到頂結束。

## 規則

### 盤面與延展
- 盤面初始 6 欄寬、16 列高, 左右各可解鎖 2 欄, 滿寬 10 欄。
- 左側與右側各有獨立的解鎖進度, 互不共用點數。
- 每側解鎖分 2 階: 第 1 階需求 6 點, 第 2 階需求 15 點(該階從 0 起算, 不累計前一階的溢出)。
- 某階達成的當下立即延展: 該側向外新增 1 欄, 盤面寬度 +1。
- 單次消行結算若同時讓某側跨過當階需求, 溢出的點數捨棄, 不帶入下一階。
- 新增的欄位自下而上補入惰性格, 補到「延展發生前、該側既有所有欄位中最低的堆疊高度」為止; 該最低堆高為 0 時新欄全空。
- 堆疊高度定義: 該欄中最高的非空格所在列號(自底部第 1 列起算), 惰性格計入。
- 兩側都達成第 2 階後盤面固定 10 欄, 不再延展。

### 目標色與顏色
- 顏色共 3 種。左右兩側各常駐一個目標色, 兩側目標色恆不相同, 且兩者全程可見。
- 目標色固定不變, 直到該側完成一階解鎖; 該側解鎖完成時重抽該側目標色, 重抽結果排除另一側當前的目標色(即從剩餘 2 色中等機率抽 1 色, 可能抽回原本那色)。
- 某側達到滿級(第 2 階完成)後, 該側目標色仍保留並繼續顯示, 不再重抽。
- 方塊的每一格顏色獨立, 由顏色 bag 依序填入: 每 12 格為一個 bag, 內含各色各 4 格, 洗牌後依序發放, 用盡再洗下一個 bag。
- 方塊形狀使用標準 7 種四格形狀, 以 7-bag 發放; 形狀與顏色兩個 bag 各自獨立。

### 消除與點數
- 一列所有格位皆非空(含惰性格)時該列成立消行。
- 消行結算順序: 先判定本次所有成立的列 → 對每一成立列各自計算同色相鄰段 → 累加點數與分數 → 一次性清除所有成立列 → 上方格位整體下落。多行同時消除時各行分開計段, 不跨行合併。
- 同色相鄰段: 在一個成立列中, 顏色等於某側目標色且水平連續的 L 格(L ≥ 2), 為該側貢獻 L−1 點。
- 左右兩側的段各依自身顏色歸屬, 互不排斥; 同一列可以同時為左右兩側貢獻點數。同一格不可能同時屬於兩側(兩側目標色恆不同)。
- 惰性格無顏色, 會截斷同色相鄰段, 本身不貢獻點數, 但計入該列是否填滿。
- 非目標色的相鄰段不產生點數, 只隨消行清除。
- 某側滿級後, 該側的同色相鄰段不再換取解鎖點數, 改以「滿級兌分率」直接換算為分數。

### 方塊與下落
- 方塊自盤面頂端中央生成(寬度為偶數時向左取整)。
- 方塊依當前落速自動下落; 落速 = 1.0 × 2^(max(0, t−30) / 60) 格/秒, t 為本局經過秒數, 無上限。
- 方塊接觸下方障礙時進入鎖定延遲 0.5 秒; 期間任何成功的移動或旋轉重置計時, 單一方塊最多重置 8 次, 超過即立刻鎖定。
- 硬降時方塊立刻落到最低可行位置並即時鎖定, 不進入鎖定延遲。
- 方塊鎖定後隨即進行消行判定, 再生成下一塊。
- 旋轉為原地旋轉, 旋轉後與牆或既有格重疊則該次旋轉失敗(踢牆規則見「待定」)。
- 每格顏色隨旋轉一同轉動。
- 不提供暫存(hold)。

### 埋點
- 每次消行記錄: 該列中每個同色連續段的長度、顏色、是否為某側目標色、當時盤面寬度、當時經過秒數。
- 每局記錄: 總方塊數、總消行數、各側解鎖達成時間、結束時間、最終分數。
- 以上資料用於與隨機基線比對段長分佈, 作為「技巧 vs 運氣」的判定依據。

## 操作

| 輸入(鍵盤) | 行為 |
| --- | --- |
| 左方向鍵 / A | 方塊左移一欄 |
| 右方向鍵 / D | 方塊右移一欄 |
| 上方向鍵 / W | 順時針旋轉 90 度 |
| Z | 逆時針旋轉 90 度 |
| 下方向鍵 / S | 軟降, 下落速度提升為當前落速的 20 倍, 且不低於 20 格/秒 |
| 空白鍵 | 硬降並立即鎖定 |
| 左右方向鍵長按 | 首次移動後延遲 150 毫秒開始連續移動, 每 40 毫秒一欄 |
| 下方向鍵長按 | 持續軟降, 放開即恢復當前落速 |
| Esc | 暫停 / 恢復(暫停時經過時間與落速不推進) |

| 輸入(滑鼠) | 行為 |
| --- | --- |
| 移動滑鼠 | 方塊橫向跟隨游標所在欄, 逐欄移動且遇阻擋即停 |
| 左鍵點擊 | 順時針旋轉 90 度 |
| 右鍵點擊 | 硬降並立即鎖定 |
| 滾輪向下 | 軟降一格 |
| 滾輪向上 | 逆時針旋轉 90 度 |

- 鍵盤與滑鼠同時可用, 後發生的輸入覆蓋前一個。
- 落點指示(ghost)全程顯示, 標出方塊硬降後會停在的位置。

## 勝負與結束條件
- 本作無勝利條件, 只有結束與分數。
- 結束條件唯一: 新方塊生成時, 其任一格與既有非空格重疊。
- 不設時間上限; 落速無上限使盤面在 300 秒前後自然不可維持, 由速度曲線單獨收局。
- 結束時凍結盤面, 顯示本局分數、本局存活秒數、已解鎖欄數, 並與最佳紀錄比對。
- 最佳紀錄只保留單一筆, 以分數為比較基準; 本局分數較高則覆寫。
- 結束後可立即重開一局, 盤面、寬度、解鎖進度、速度全部重置。

## Demo 範圍邊界
- 不做: 局間成長、收藏、關卡地圖等元 progression
- 不做: 速度以外的第二套壓力來源 — 道具、障礙塊、特殊史萊姆一律不做
- 不做: 每側 3 階以上的完整解鎖階梯與出貨用難度曲線, Demo 只做到 2 階
- 不做: 全盤下沉一行的補償機制
- 不做: 暫存(hold)機制 — 它會大幅降低排色的規劃難度, 直接汙染「技巧 vs 運氣」這題的答案
- 不做: 連消(combo)、Back-to-Back 等額外計分規則 — 會把玩家注意力從排色拉回傳統 Tetris 的消行節奏
- 不做: 難度選擇、起始等級選單 — 速度曲線必須全體玩家一致, 否則埋點資料無法橫向比對
- 不做: 排行榜、雲端紀錄、帳號 — 最佳紀錄只存單機單筆
- 不做: 教學關卡與引導流程 — Demo 以口頭說明帶入, 避免引導本身影響玩家是否「自發」排色
- 不做: 目標色的手動指定或重抽功能 — 玩家若能選色, 測到的就不是排色技巧
- 不做: 惰性格的額外互動(專屬消除、轉色、數量獎勵)
- 不做: 暫停期間的盤面操作
