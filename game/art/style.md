# 史萊姆擴張 v13 美術規格

RD 只讀這份。對應 `spec.md` v13 / `guide.md` v13。函式全掛在 `window.Art`, 參數固定 `(ctx, state)`, 各自 save / restore。

**index.html 必須宣告 `<meta charset="utf-8">`**(art.js 內含中文字串; 沒宣告在 file:// 下會亂碼)。字型只用系統字(微軟正黑體 → PingFang TC → Noto Sans TC → sans-serif), 不載外部資源。

## 1. 邏輯畫布尺寸

**960 × 640**(`Art.canvas`)。格子邊長 **26**(`Art.cellSize`)。

## 2. 座標約定(盤面類函式共用)

- `x` = **絕對欄**(-2 ~ 7, 開局 0~5), `y` = **列**(1 = 最底列, 19 = 頂列, 20 以上 = 不可見區)。與 spec 的座標系相同, RD 不需換算
- `y` 可帶小數(重力下落、方塊下落的插值), 同一組格位要有相同的小數部分
- **盤面外框固定為滿寬 10 欄**: 絕對欄 -2 的左緣永遠在 x=350, 右緣 x=610; 列 1 底緣 y=604, 列 19 上緣 y=110。延展時盤面不位移, 未開的欄畫成「預留槽」(斜紋暗格)
- 所有盤面類函式會把內容裁切在列 1~19 內, **y > 19 的格位傳進來也不會畫出來**(不可見區), RD 不必自己過濾
- `Art.cellRect(x, y)` 回傳該格像素矩形, `Art.board` 給盤面邊界常數, 供除錯用

## 4. 形狀語言

圓角方塊的扁平史萊姆(頂部高光、底部暗帶、中央記號); 系統標示一律是「線」(框、連接桿、箭頭、斜紋), 不用填滿色塊, 以免和史萊姆本體混淆。

## 5. 理念落實

- **P0 辨識度先於好看**: 三色明度拉開三檔(黃亮 / 紅中 / 藍暗), 每色再配一個幾何記號; 重力球是唯一的圓形本體(其餘都是圓角方), 放棄所有裝飾性背景
- **P1 視覺權重跟著決策迫切度走**: 最亮的是操作中方塊(白框)與落點; 事件橫幅固定在盤面上方的專屬帶(y 18~72), 側欄的目標色與任務數字有獨立矩形, 任何事件都不疊在它們上面
- **P2 規則上存在的東西, 畫面上就必須存在**: 懸空塊用共同輪廓 + 格間連接桿表達「整塊一起動」; 零位移重力事件有獨立的「內收虛線環 + 橫槓 + 無下落」; 錨點在不可見區的顆數貼頂線畫並加向上小三角; 未開的欄以預留槽畫出來
- **P3 一個意義一種長相**: 白 = 消除、青 = 重力、紫 = 削頂、綠 = 開欄與獎勵、橘 = 結束; 預覽、落點、盤面、說明頁、消除結算標記全部用同一套史萊姆與重力球畫家
- **P4 關鍵區分至少兩條通道**: 三色 = 色相 + 明度 + 記號; 消除 / 削除 / 下落三種標記 = 顏色(白 / 紫 / 青) + 形狀(縮小單框 / 斜紋 / 上方拖尾); 一般消除 vs 追加消除 = 顏色(白 / 青) + 形狀(單框 / 雙框加「↓ 下落後消除」字樣); 重力事件中要掉的塊 vs 不動的塊 = 顏色(青 / 灰) + 形狀(實線加向下 V / 點線加 ⊥ 錨)

## 6. 物件表

未列 state 欄位的預設: 省略即視為「沒有 / 0」。t 一律為該呈現時段的進度 0~1(RD 依 spec 的呈現時長換算)。

| spec 物件 | 函式 | state 欄位 | 各狀態視覺 |
| --- | --- | --- | --- |
| 背景 | `drawBackground(ctx)` | — | 全畫面底色。每幀最先畫 |
| 盤面邊界 / 不可見區 | `drawBoard(ctx, s)` | `minCol`, `maxCol`(目前已開的絕對欄範圍, 開局 0 / 5) | 已開範圍: 深底 + 格線 + 淺色邊界框; 未開的欄: 斜紋預留槽; 頂線: 橘色虛線 +「頂線」小字。寬度 6~10 由 minCol/maxCol 決定 |
| 盤面格位 | `drawCell(ctx, s)` | `x`, `y`, `kind`: `'empty'`/`'color'`/`'ball'`, `color`: `'A'`/`'B'`/`'C'`, `mark`: `'none'`/`'clearing'`/`'shaving'`/`'falling'`, `t` | 空: 不畫(盤面底色即空格, 開放 / 封閉空洞不區分, 依 spec); 已填色: 史萊姆; 已填球: 重力球; **消除標記中**: 白色單框 + 本體隨 t 縮小閃白; **削除標記中**: 紫色斜紋 + 紫框, 本體淡出; **下落中**: 本體 + 上方三道青色拖尾(`y` 給插值座標) |
| 重力球格位 | `drawGravityBall(ctx, s)` | `x`, `y`, `mark`, `t`(同 drawCell) | 等同 `drawCell` 的 `kind:'ball'`。已鎖定: 暗底銀球 + 三色環 + 向下箭頭; **成團消除中(觸發)** = `mark:'clearing'`, 另多一圈青色外擴環; 隨重力事件下落 = `'falling'`; **被削頂 = `'shaving'`, 沒有青色環**(削頂不觸發); 隨方塊下落 → 由 `drawPiece` 畫 |
| 同色團顆數標示 | `drawClusterCount(ctx, s)` | `x`, `y`(錨點 = 團中 y 最大、同 y 取 x 最小), `n` | n=2 / 3: 錨點格右上角 13×13 黑底白字徽章; 其他 n 不畫。錨點 y>19 時貼頂列畫, 徽章上方加向上小三角(表示團延伸到看不見的地方) |
| 懸空結構標示(常駐) | `drawFloatingMark(ctx, s)` | `cells: [{x,y}]`(一個懸空連通塊), `group`(塊序號 0,1,2…) | 一塊呼叫一次。淡青底 + 沿整塊外緣的青色輪廓 + 塊內相鄰格之間的青色連接桿; group 偶數長虛線、奇數短虛線, 讓斜角相碰的兩塊也分得開。不懸空的塊不呼叫。**不表達下落格數** |
| 懸空結構(事件中) | `drawFloatingEventBlock(ctx, s)` | `cells: [{x,y}]`, `role`: `'fall'`/`'stay'`, `t` | 重力事件期間, 受影響的每一塊呼叫一次: **受影響且懸空(將下落)** = 青色實線粗輪廓 + 每欄最低格下方向下 V; **受影響但不懸空(不動)** = 灰色點線輪廓 + 最低格底下 ⊥ 錨; **不受影響** = 不呼叫。事件期間可與 drawFloatingMark 並存, 建議改用本函式 |
| 重力事件指示 | `drawGravityEvent(ctx, s)` | `x`, `y`(觸發點: 含球團的錨點或球原位), `size`: `'small'`/`'large'`/`'zero'`, `t` | 小型(<10 格): 單圈青環外擴; 大型(≥10 格): 雙圈 + 八道放射線, 半徑約兩倍; **零位移**: 灰青虛線環「往內收」+ 中央橫槓 + 上方「無下落」字樣。消失 = 不呼叫。多事件依序各呼叫, 不合併 |
| 追加消除指示 | `drawExtraClear(ctx, s)` | `cells: [{x,y}]`, `t` | 每格青色雙框 + 團上方「↓ 下落後消除」標籤。格位本體照樣用 `drawCell(mark:'clearing')` 畫, 本函式疊在上面 |
| 消除結算標記 | `drawClearResult(ctx, s)` | `cells: [{x,y,isTarget}]`, `deducted`(本次扣了幾顆), `balls`(本團含幾顆球), `targetColor`, `t` | 目標色格左下角白色倒三角(= 扣 1); 團上方黑底白框標籤「[目標色小史萊姆] 目標 −N ・ [小球] 球 ×n」, 隨 t 上浮, 末段淡出。deducted 與 balls 皆 0 時不出標籤, 只有格上記號 |
| 落下方塊 | `drawPiece(ctx, s)`(`drawPlayer` 為同一函式) | `cells: [{x,y,kind,color}]`, `mode`: `'falling'`/`'softDrop'`/`'lockDelay'`/`'locked'`, `lockT`(鎖定延遲進度 0~1) | 下落中: 本體 + 整塊白色細外框; 軟降中: 另加頂部白色速度線; 鎖定延遲中: 白色粗虛線框 + 隨 lockT 變亮的白色罩; 已鎖定: 一幀白閃(之後改由 drawCell 畫)。y>19 的格自動看不見 |
| 落點指示(ghost) | `drawGhost(ctx, s)` | `cells: [{x,y,kind,color}]` | 每格: 該色細框 + 淡填 + 記號線稿; 球格: 銀色圓框 + 向下箭頭線稿。不含任何預測 |
| 下一塊預覽 | `drawNextPreview(ctx, s)` | `cells: [{dx,dy,kind,color}]`(相對格, dy 向上為正), `masked` | 右上面板置中畫整塊(格子 26, 與盤面同尺寸); 含球時右下角青字「含重力球」; 遮蔽中: 面板只顯示「—」 |
| 目標色指示 | `drawTargetColor(ctx, s)` | `color`, `announcing`, `t` | 左上面板: 大史萊姆 + 色名(紅 / 藍 / 黃)+「記號: 圓/方/三角」; **換色公告中**: 面板框變綠並脈動, 右上角綠色「新目標」標籤 |
| 任務進度 | `drawTaskProgress(ctx, s)` | `stage`(當前階 A+1), `remaining`, `required`(本階需求), `phase`: `'expand'`/`'extend'`, `color`(目標色, 給進度條上色) | 標籤「開地」(綠)/「延伸」(灰藍)+「第 N 階」; 大字「剩餘 X 顆」; 進度條(目標色填色)+「已消 / 需求」; **remaining ≤ 0**: 改顯示綠字「已達成, 待結算」, 進度條全滿變綠, 不顯示負數 |
| 下一次延展側指示 | `drawNextExpandSide(ctx, s)` | `side`: `'left'`/`'right'`/`null`, `col`(下一次會開的絕對欄: 左 = minCol−1, 右 = maxCol+1) | 在那一格預留槽畫綠色虛線框, 盤面下方畫朝外的綠箭頭 +「下次開這側」。`side` 為 null(已滿寬) = 不畫 |

| 延展獎勵削除指示 | `drawShaveIndicator(ctx, s)` | `perCol: [{x, count}]`, `total` | 盤面頂端上方每欄紫字「−k」(0 格為灰色 0); 其上紫框標籤「削頂 共 −N 格」。**延伸關卡的削頂獎勵也用這支** |
| 滿寬完成獎勵指示 | `drawFullWidthBonus(ctx, s)` | `t` | 盤面中上方綠框黑底卡片「滿寬完成 +1,500」, 開頭 0.12 內彈出。只在第 4 次延展事件內呼叫 |

### 不需獨立函式的 spec 物件

| spec 物件 | 由誰呈現 | 理由 |
| --- | --- | --- |
| 同色團 | `drawCell` + `drawClusterCount` + `drawCell(mark:'clearing')` | 團本身就是一群格位; 未達門檻的狀態由顆數標示表達, 成立消除由消除標記表達, 沒有額外的團外觀 |
| 空洞 | `drawBoard`(空格 = 盤面底色) | spec 明定開放 / 封閉不做區分呈現 |
| 不可見區 | `drawBoard` 的頂線 + 所有盤面函式的裁切 | 規格上就是不可見, 沒有可畫的東西 |
| 遊戲狀態 | RD 依狀態決定呼叫哪些函式 | 狀態機本身不是畫面物件 |

## 7. 每幀繪製層級(由下往上)

1. `drawBackground`
2. `drawBoard`
3. `drawNextExpandSide`(畫在格位之下, 虛線框只落在空的預留槽)
4. `drawCell`(所有已鎖定格位, 含 mark)
5. `drawFloatingMark`(每個懸空塊一次)/ 重力事件期間改 `drawFloatingEventBlock`
6. `drawClusterCount`(每個 n=2/3 的團一次)
7. `drawGhost` → `drawPiece`
8. 結算標記: `drawClearResult` / `drawGravityEvent` / `drawExtraClear`(依結算時序, 同一時間只出現其中一種)
9. 獎勵事件: `drawExpandEvent` 或 `drawExtendReward`, 加上 `drawShaveIndicator` / `drawFullWidthBonus`
10. 側欄: `drawTargetColor`, `drawTaskProgress`, `drawSupplyRemaining`, `drawNextPreview`, `drawHud`
11. 暫停時: `drawPauseMask`(蓋住以上全部); 說明畫面: `drawGuidePage`(蓋住全部)
12. 結束時: `drawGameOver`
13. 最上層: `drawAbandonTimer`(長按 R 期間, 暫停中也畫)
