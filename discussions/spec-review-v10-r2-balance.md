# spec-review v10 r2 — 數值

## 題 1|第 6 階起 +4/階不封頂之後的最強檔

**結論: 局長與最終 S 完全不變, 294 秒, S=6。沒破線, 但裕度仍是 0。**

與 r1 的封頂 24 逐格相同 — 封頂值 24 與「20 再 +4」恰好同值, 差異只出現在 S7(28 vs 24), 而 S7 從來沒被走到。

**無限延續**: 不封頂後更安全。第 n 階(n≥6)消耗包絡 = 11.5n 格, 回收固定攤平 25.7 格/階。消耗 > 回收 ⟺ n > 2.2, **恆成立且發散**, 不需要再設紅線。

**若破線該動哪一個**: **就是遞增斜率本身**(R 從「封頂值」變成「斜率」, 同一個旋鈕換了參數化方式)。

**但要先講清楚**: 最強檔的 294 秒**不是後段需求撐出來的, 是 S4 削頂(+36.6)與 S5 補給(+16)兩筆早期回收撐出來的**(合計 +26 塊 ≈ +33 秒)。前 5 階的需求無論怎麼排都會在死亡前達成, 所以**前 5 階不是局長旋鈕, 斜率才是** —— 而斜率只在 S≥6 生效, 目標檔與強檔到不了, 等於是一個只對最強檔生效的乾淨旋鈕。

供給砍幅按各檔自己的分邊效率走, 不是齊頭 0.65:

| 強 | 2.5 | 0.70 | 0.833 | **0.583** | ×0.70 |

**不下修會怎樣**: 沿用 5/8/12, 目標檔 S1@55.7 ✓ / S2@72.9 ✓ / S3@**98.7 ✗**(死在 81.2)→ **S=2, 倍率那一階再度看不到** —— 位置條件把 r1 前置需求剛解掉的問題原樣退回去了。

**下修幅度: 前 5 階等比乘 0.65 → 3 / 5 / 8 / 11 / 14**。目標檔滿寬後可用合格格 = 16.9 顆, 恰好容得下 3+5+8 = 16。

## 題 3|帶懸空標示跑第 4 輪的預期值修正

標示改變的是 **p_位移(0.5 → 0.7)**, 不改變盤面幾何。所以**比率型門檻要下移或維持, 絕對次數型要等比上調**(位移事件 5.3 → 7.4 次/局, +40%)。

### 空轉事件

| 燈號 | r1(無標示) | **第 4 輪(有標示)** |
| --- | --- | --- |
| **預期值** | 0.45~0.60 / 4~6 次 | **0.25~0.35 / 2~4 次** |
| 綠 | ≤0.35 / ≤3 | **≤0.25 / ≤3** |
| 黃 | 0.35~0.60 / 3~6 | **0.25~0.45 / 3~5** |
| **紅** | ≥0.65 / ≥7 | **≥0.50 / ≥6, 3 局皆然** |
| 反向警戒 | ≤0.15 | **≤0.10** |

**門檻不等幅下移的理由**: 標示消掉了「玩家不知道哪裡懸空」這個混淆項。沒有標示時高空轉率可能是規則太窄**也可能**是玩家不會用, 只能設寬門檻; 有標示後高空轉率**只剩一種解釋**, 判定可以更嚴, 紅線一旦觸發可直接歸因到懸空判定。

### 大型事件

| 燈號 | r1 | **第 4 輪** |
| --- | --- | --- |
| **預期值** | 目標 0.3~0.8 / 高手 1~2 | **目標 0.6~1.1 / 高手 1.5~2.8**; 佔比 8~12%(不變) |
| 綠 | ≤1 / ≤15% | **≤1.2 / ≤15%** |
| 黃 | 1~2 / 15~30% | **1.2~3 / 15~30%** |
| **紅** | ≥3 / ≥30% | **≥4 / ≥30%, 3 局皆然 + 回饋讀成沉降** |

**佔比門檻 15%/30% 一個都不動** — 它是盤面幾何的性質, 與標示無關。**讀數請以佔比為主、次數為輔**, 佔比不受標示、不受出現率、不受局長影響, 是三個埋點裡唯一乾淨的。

### 順帶受牽動的
- 追加消除: 1.1 → **1.5 次/局, 佔 4%**; 紅線 **≥5 次/局**(原 ≥4)或佔比 ≥12%(不變)
- 單次最大下落格數: **2~4 格不變**

### 對局長的回饋
標示把 p_位移 0.5→0.7, 重力回收 g 從 0.235 升到 0.33:
- 目標檔: ΔV_eff 2.87→2.77, N 81→84 塊, **局長 211 → ~217 秒**(仍在 190~230 內)
- 強/最強: **不變**(模型本來就假設 p_位移 0.65~0.70)

**題 1、2 的表不需要重做**, 最強檔 294 秒不受影響。
