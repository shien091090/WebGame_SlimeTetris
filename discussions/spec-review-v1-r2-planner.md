# spec-review v1 r2 — 企劃

## 1. 「餵左還是餵右」存不存在 → 存在, 但我 r1 的講法錯了, 修正立場

數值講對了一半: 段的**歸屬**確實由顏色自動判定, 玩家不能把紅段改派給右邊; 但取捨不在歸屬, 在**放置資源的分配** — 一塊混色四格只有一個落點與一個旋轉態, 玩家想讓紅格貼上左側既有紅段, 就放棄了同一塊把藍格對齊右側藍段的位置, 兩者空間上互斥, 這才是每塊都要做的那個決定。所以我把主張修正為「每塊決定這次的落點服務哪一側」, 不再用「這段餵左還是餵右」這個會被誤讀成結算選項的說法, 建議 decisions.md 那一行也一併改寫。修法選 **(a) 右側需求錯開 10/20**: 它不動排色機制本身, 純靠進度不對稱讓玩家產生「集中補落後那側 vs 順手做領先那側」的傾向, 反而把上面那個分配取捨放大, 同時把四次延展拆成四次獨立事件。(b) 讓玩家指定歸屬等於取消顏色約束, 排色從空間規劃退化成結算時點選單, 會直接把驗證問題的答案汙染成「玩家會不會按按鈕」, 不能做。

## 2. 前 150 秒平台期 → 是問題, 而且是比無聊更嚴重的問題

它不是「難度不夠」, 是**核心取捨在前 86% 的時間裡不存在**: 重力綁不到玩家, 「再忍一塊把段養長」的成本就是零, 玩家可以無限忍, 那條「現在消行求生 vs 養段」的張力整局只在最後懸崖出現一次。更糟的是驗證問題會被這件事騙過去 — 在無壓力下測「能不能有意識排色」, 答案必然偏樂觀, 出貨版一加壓就不成立。我要的方向是**前段就要有壓力**, 而且壓力必須來自重力真的咬得到玩家(讓軟降/硬降不再是免費的), 不是靠解鎖節奏撐場面; 解鎖節奏只能解決無聊, 解不了取捨消失。取捨要攤開: 提早讓重力生效會壓縮新手保底 60 秒這條定案, 請製作人在「保底 60 秒」與「取捨全程有效」之間裁決, 我的意見是後者優先, 因為 Demo 要驗的那題依賴它; 至於曲線怎麼改才能同時守住兩者, 交數值同事算。

順帶: 我同意數值對 12 格 bag 的批評。壓掉「單塊含同色 ≥3 格」等於砍掉玩家排長段最有力的工具, 這與我 r1「不給即時段提示、測純粹能力」的主張疊加後就是雙重壓抑 — 我撤回一半: 提示可以繼續不給(那是玩家自己的觀察能力), 但 bag 粒度不該再壓變異, 請數值同事重估。

## 3. 驗證計畫補完

**主要統計量 — 段長 delta 的可算定義**: 定義盤面「目標色相鄰對數」= 對每一列、每一段顏色等於某側目標色且水平連續的 L 格(L≥2)計 L−1, 全盤加總, 左右兩側分開算; delta = 該方塊鎖定後的值減去鎖定前的值(惰性格與消行清除不計入此次 delta, 消行另行記錄)。主要指標是**每方塊平均 delta(玩家)對比同一份形狀/顏色序列餵給隨機放置 agent 跑出的平均 delta**, 次要指標是消行時 L≥3 段佔全部目標色段的比例 — 前者測意圖, 後者測意圖有沒有轉成實際收益。

**樣本計畫**: 8~10 人(含至少 3 名沒玩過方塊類的), 每人連玩 5 局; 第一局標記為熟悉局, 不進主分析, 但務必保留 — 第 1 局與第 4~5 局的 delta 差就是「這件事學得會」的證據, 若兩者無差異, 那就是運氣而不是技巧, 這比和隨機基線比更有說服力。另需記錄暫停總時長, 暫停佔比過高的局次從主分析剔除。

**賽後三問**: (1)「這局你有沒有刻意想把某個顏色排在一起? 是哪一側、你怎麼判斷該做哪一側?」(測意圖與分配取捨是否被感知到) (2)「有沒有哪一塊你明明可以消行卻忍住沒消? 描述一次。」(測核心取捨是否真的發生, 也用來交叉驗證第 2 題的平台期問題) (3)「盤面變寬之後, 排色有變得比較容易嗎? 哪裡變容易?」(測解鎖回饋鏈是否被感知, 並與分寬度切片的埋點資料對照)。
