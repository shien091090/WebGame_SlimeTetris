### (2) 規則矛盾或沒定義的情況
- **暫停恢復時仍按住的方向鍵,沒有定義。** v24 只管到「結算解鎖」這個時點,但還有兩個時點會遇到按住的鍵:
  - 局中按 Esc 恢復;
  - 叫出說明,關閉後回到暫停,再恢復。

  埋點已經有「暫停截斷」這種結束方式,表示按住的鍵在暫停時會被截斷,但恢復時若還按著,該當成剛按下、要先放開,還是照舊,規格沒寫。
  - 還有一種情況更容易出問題:在過場中按了暫停,會排到結算第 8 步才生效。這時「解鎖」和「進暫停」是同一步,順序沒定。如果解鎖先發生,一般結算會先讓方塊移 1 欄才進暫停;恢復之後該套「過場後要先放開」,還是套暫停的規則,也沒寫。
  - 建議:暫停恢復一律「先放開再按」,跟過場、關閉開場說明、放棄後的 R 用同一條規則;第 8 步寫死「先生效排隊中的暫停,再處理按住的鍵」。
- **從結束畫面或通關畫面按 R 重開時,按住的方向鍵與硬降鍵沒有定義。** 關閉開場說明時要求先放開,重開卻沒寫。建議照開場說明的規則。
- **硬降鍵、旋轉鍵按住跨過結算,沒有定義。** 規格只寫了「結算期間的按下事件丟棄」,遊戲中也沒寫「只認剛按下的那一下,忽略系統的自動連發」(這句只寫在說明畫面)。
  - 風險:如果實作把瀏覽器的按鍵自動連發當成新的按下,按住空白鍵跨過 4~6 秒的過場,解鎖後新方塊會當場被硬降,左右鍵也可能跟 DAS / ARR 疊在一起多移一格。老闆說的「一按就過頭」和這個有沒有關,目前讀不出來。
  - 建議:「操作」章寫死遊戲中所有按鍵都忽略系統自動連發;硬降鍵跨過任何結算都要先放開再按。
- **第 1 星塊數的讀法會同時觸發兩條,也有情況一條都不中。**
  - 同時觸發:有一局停在 0 星、中位數又小於 6,或者一次完成的局達 1/3、同時有一局停在 0 星。這時一條要改 5、一條要改 7,沒有定誰優先。
  - 一條都不中:中位數落在 6~12、沒有 0 星的局,但有一局超過 16 塊。這時不符合「不動」的條件,也不符合任何一條要調整的條件。
  - 這是數值讀數的規則,建議請數值補優先順序與漏掉的那種情況。
- **次要:** 逐次左右按下的自我校驗只寫了「一般按下」那一種來源。「解鎖時當成剛按下」按住不到 170 毫秒也應該只移 ≤ 1 欄,可以一併校驗。

### (3) 操作能不能撐起核心循環、是不是只用一種輸入
- 只用鍵盤,按鍵足以撐起「選落點與旋轉,決定湊哪一團、用不用重力球或清色球」這一個取捨。重力球、清色球、過場、任務都沒有新增任何按鍵。
- 體驗風險(不是缺漏,製作人已裁決,只是提醒試玩時注意):一般結算解鎖時「當成剛按下,立刻移 1 欄」這條,會碰到一個很常見的習慣——按住方向鍵把方塊貼著牆滑到鎖定。有這習慣的玩家,每一塊新方塊一出現都會被帶走 1 欄。第 0、1 星落得慢,可以自己修回來;後段落速快,這 1 欄就是實際的放錯。試玩除了看「解鎖時當成剛按下」有沒有低於 2%,也建議看這類按下之後玩家有沒有立刻往反方向按。

### (4) Demo 要驗證的問題驗不驗得到
- 驗得到:
  - 升段感:靠每一星的取得時點與耗時,加上試玩提問;
  - 過場會不會想跳過:靠逐過場的按鍵次數,第 2~4 個過場單獨讀;
  - 卡關的牆:靠逐任務的塊數與「一次完成」欄位。

  每種失敗的樣子都有對應的讀數。
- 有一個會讓讀數失真的因素:v24 之後,過場結束時按住的鍵不算數,玩家可能會在過場快結束時先按方向鍵「預備」。這些按下會被算進過場按鍵次數,讀成「不耐煩」。目前過場按鍵只按鍵種記總數,分不出這兩種。建議每一次按下多記一個欄位:落在第幾段、距過場結束幾毫秒。只把在第 1~3 段按的算成「想跳過」,最後一段尾端按的另外讀。這是數值與製作人轉寫的埋點,不是規則改動。

### (5) 玩家說明
- **第 3 頁的「目標」塊跟遊戲內面板對不上。** 說明寫「目標色的史萊姆圖示」,規格裡面板的目標是「消掉[目標色]」,也就是「消掉」兩個字加上圖示。說明原則要求示意圖和遊戲內是同一個東西。建議改成照遊戲內的寫法。
- 玩家會操作到的動作沒有漏:移動、順轉、逆轉、轉半圈、軟降、硬降、Esc、H、Enter、按住 R 放棄、R 重開、說明畫面翻頁都有出現。
- 沒有違反說明原則,也沒有教 Demo 要驗證的行為:
  - 第 3 頁只講「有任務、目標看面板、解完有獎勵或解鎖、星數 +1」,屬於必寫的「目標」,沒有教怎麼追任務;
  - 核心取捨那頁已經刪掉;
  - 沒有預先介紹特殊球。
- 「過場後要先放開再按」和「過場中不能放棄」沒寫進說明。我判斷不需要寫:這兩條不是新的動作,寫了會多一頁或多一句。如果試玩時有人以為過場後是卡頓,再考慮補。
